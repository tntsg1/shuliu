# 束流 BEAMLINE 完整版规划（grilling 记录）

Demo（M1）已于 2026-11-07 验收通过。以下为完整版规划定案，逐轮追加。

## 第一轮（2026-11-07）

| # | 决策 | 定案 |
|---|---|---|
| F1 | 1.0 规模 | 精简 1.0：8 阶段、饰品约 50、设备约 15、事件约 12、无尽模式；其余靠免费更新追加 |
| F2 | 局外成长 | 实验室逐层开放：每开一层带来一个新系统（地下储藏室、教授办公室、其他实验站……），配合内容解锁，不加基础数值 |
| F3 | 叙事 | 极简：只靠物品描述、考核邮件、墙上便条 |
| F4 | 发售节奏 | 不做 Demo、不做抢先体验，做完 1.0 一次发售 |
| F5 | 平台 | Windows / Steam 先行，保证 Steam Deck 顺畅（手柄全支持、小屏可读）；主机/手机 1.0 后再议 |
| F6 | 语言 | 开发期只做中文；上 Steam 前补齐简中、繁中、英文、日文 |
| F7 | Steam 功能 | 先不做（成就、云存档、每日种子排行榜都暂缓） |
| F8 | 宣传 | 先不做（网站介绍页、宣传片、商店素材暂缓） |
