# 任务：实验室主场景“去 AI 味”第一阶段（交给外部模型实施）

> 项目：《束流 BEAMLINE》，Godot 4.7（GDScript），2D 推运气 roguelite。
> 源码：`E:\godot\shuliu`。导出到：`E:\godot\shuliu_build\BEAMLINE.exe`。
> Godot：`E:\godot\godot47\Godot_v4.7-stable_win64_console.exe`
> **先完整读一遍 `design/视觉规范.md`**，本任务就是把实验室主场景按那份规范收拾一遍。
> 本次只做**减法和清错**，不重新设计任何设备的造型。

---

## 1. 目标

用户觉得画面“AI 味重”：每样东西单看都还行，放在一起像拼起来的。本阶段要做到：
1. 颜色收住：背景物件不再用彩虹色。
2. 标签减少：删掉装饰编号。
3. 不再有东西互相压住，文字不被线穿过。
4. 线宽分成四档。
5. 纸有固定方式，地上的东西有接地影。
6. 重复花纹压淡。

做完交一组**同机位的前后对比图**给用户确认。

## 3. 具体要改什么

### 3.1 线宽分档

- 在 `scripts/util/ink.gd` 顶部加：
  ```gdscript
  const W1 := 2.4   # 主轮廓
  const W2 := 1.4   # 结构线
  const W3 := 0.9   # 注释、纸边、刻度
  const W4 := 0.6   # 纹理（颜色透明度 ≤ 0.25）
  ```
- 第 2 节列出的文件里，每个 `Ink.box / Ink.frame / Ink.line / Ink.pl / draw_line / draw_arc` 的线宽都换成这四个常量之一，按规范第 1 节的表决定用哪档。
- 楼上办公室（`_office`）和楼下储藏室（`_storage`）是背景层，整体降一档（外轮廓 W2，内部 W3）。

### 3.2 颜色收住

- **书架**（`lab.gd` `_office()` 里的 `books`）：16 本书改成以底色为主。书脊用 `equip_dark`、`paper2`、`slab`、`ink2` 和 `office` 混出 4–5 种相近的旧纸、旧布颜色。只留 **2 本**有颜色：一本 `red`、一本 `blue`，都和 `office` 混 55%。斜靠的那本也改成底色。书脊上的白条保留，透明度降到 0.4。
- **储藏室箱子**（`_storage()` 里的 `boxes`）：全部改成纸箱色，用 `equip_dark` 和 `paper2` 两种交替。可以在少数箱子上画一条胶带（`gold` 混 `storage` 60%），不写字。
- **储藏室货架**：10 个一模一样的货架改成 6 个，间距和高度有变化（例如一高一矮交替），留出至少一段 250 px 以上的空墙。
- 其他颜色不动。探测器的紫色、注入器能级管的色阶、三色电缆、氢气瓶都保留（规范第 4 节的例外）。

### 3.3 删标签

删掉这些（直接删那一行 `Ink.sticker` / `Ink.text`）：

| 文字 | 位置 |
|---|---|
| `MB-1847`、`MB-1848` | `lab.gd` `_main_ring()` |
| `km 18.42` | `lab.gd` `_main_ring()` |
| `SEPTUM 引出`、`本站支线` | `lab.gd` `_main_ring()` |
| `距下一个实验站 EXP-8 · 3.3 km ►` | `lab.gd` `_main_ring()` |
| `INJ-1` | `lab.gd` `_injector()` |
| `D-01`、`Q-02`、`Q-03` | `lab.gd` `_magnets()`（`_magnet()` 的 label 参数传空串时不画贴纸） |
| `探测器 DET-A` | `lab.gd` `_detector()` |
| `DET-A READY` | `detector.gd` 第 118 行左右 |

改这些：

| 原文 | 改成 |
|---|---|
| `◄ 主环 MAIN RING · 周长 26.7 km · 二极铁 1232 块` | `◄ 主环 · 周长 26.7 km`，字号 13，`Pal.hand`，颜色 `ink2`。位置挪到不压任何东西的地方（见 3.4） |

保留不动：`注入器`、`采购终端`、`辐射控制区`、`束流运行中 · 勿开舱`、`护身符`、`失物招领`、黑板上的三行字、`本轮配额：3 瓶`、墙上两张纸和审核台上的全部文字。

### 3.4 修互相压住和穿线

现有截图 `shots/tut_04_bottles.png` 里能看到这几处：
1. **“经费处理决定”压住了辐射警示牌下面的“辐射控制区”**：纸是 `notice.gd` 的 `NOTE := Rect2(640, 318, 100, 150)`，警示牌在 `lab.gd` 的 `_trefoil(Vector2(770, 356), 26)` 和 `Vector2(770, 408)` 的字。把警示牌和字一起往右挪，挪到和纸之间至少空 16 px 的位置，并且不能挡住 Q-02 磁铁和观测舱外框。
2. **评审日程表和经费处理决定挨得太近**：`SCHED` 右边和 `NOTE` 左边之间至少空 16 px（算上旋转后的角）。可以把 `SCHED` 稍微往左挪，左边别压住注入器和梯子。
3. **“主环…”那一行字被一条横线从中间穿过**（截图里 y≈290，x 从 290 到 650）。找到这条线是谁画的（可能是主环管道的下沿、吊架、或者 `notice.gd` 纸上的东西），然后把文字挪开，文字上下左右 6 px 内不许有线。
4. 挪了 `NOTE` 或 `SCHED` 之后，**教程里指向它们的箭头位置要跟着改**：`scripts/ui/tutorial.gd` 第 28 行 `wall` 这一步的箭头写死在 `Vector2(560, 372)`（指日程表），改成跟着 `SCHED` 的中心算，便条位置 `Vector2(1080, 300)` 不动。气瓶那一步（第 34 行 `Vector2(350, 690)`）如果气瓶架没挪就不用改。
5. 改完后全场景再找一遍：任意两张纸、纸和牌子、文字和线之间都不许重叠。

### 3.5 纸的固定方式和投影

场景里每一张纸、每一块牌子都要有固定方式和投影（规范第 2、3 节）：

| 东西 | 现在 | 要加 |
|---|---|---|
| 评审日程表 | 顶部有一条黄胶带、有投影 | 保留 |
| 经费处理决定 | 有红色图钉 | 加投影（右下 4,5，透明度 0.12） |
| 主环地图（`ringmap.gd`） | 什么都没有 | 两个上角各一小段胶带 + 投影 |
| `束流运行中 · 勿开舱` 牌子 | 一个框 | 四角各一颗小螺丝（`Ink.rivet`，半径 1.6）+ 投影 |
| 辐射警示牌 | 一个圆 | 投影 |
| 黑板 | 一个框 | 投影 + 底边一条粉笔槽（二档线宽，`equip_dark`） |
| 挂钟 | 一个圆 | 投影 + 正上方一颗挂钉 |
| `本轮配额：3 瓶` 贴纸 | 贴纸 | 保留 |

纸的颜色统一用 `Pal.c("paper")`。`notice.gd` 里有写死的 `Color("#f7f2e6")` 和 `Color("#2b2a28")`，暗色模式下不会换色，**这次不要改**它们的颜色值（墙上的纸在暗色模式下保持亮色是故意的），只加投影和固定件。

### 3.6 接地影

所有站在地面（`Geo.FLOOR`）上的东西，底边加一条接地影：高 4 px，黑色透明度 0.15，左右各比物体宽 6 px，画在物体**下面**（先画影子再画物体）。包括：注入器底座、三个管道支架脚、三个磁铁支脚、探测器底座、采购终端、灭火器、气瓶架底板、控制台桌、审核台、梯子底端、主角双脚。

### 3.7 梯子和主角接触点

- **梯子**（`lab.gd` `_stairs()`）：现在用 `Ink.line` 画的抖动长线，和旁边干净的设备不像一个人画的。改成：两根直的侧梁（W1，`equip_dark` 填色的窄长条，`Ink.box`），台阶用二档线宽，台阶两端插进侧梁里。不要抖动。
- **主角**（`player.gd`）：不改造型，只检查三个时刻的截图：站在控制台前按红色按钮、拉拉杆、站着不动。手要碰到按钮或拉杆把手，脚底要落在地面线上。差几像素的话调偏移量；如果要大改姿势，**不要改**，写进汇报里。

### 3.8 重复花纹压淡

- 剖切斜线（`_section()`）：斜线间距 9 → 12，颜色透明度降一半，线宽 W4。上下两条边线保留，用 W2。
- 墙板缝（`_main_room()` 里每 160 px 一条竖线）：改成 W4，颜色透明度 0.5。
- 磁铁线圈排线、探测器横纹：W4。

## 4. 代码规矩（必须遵守，项目里踩过坑）

1. 画字一律用 `Ink.text / Ink.para / Ink.size / Ink.para_size`。不要用 `draw_string`、`get_string_size`。
2. 不要新加 `draw_circle`、带抗锯齿的 `draw_polyline`、`draw_rect(..., false)` 描边。圆用 `Ink.disc`，框用 `Ink.frame`，折线用 `Ink.pl`。
3. 哑光平涂，不发光，不加渐变。
4. 颜色从 `Pal.c("名字")` 取（3.5 节说的 `notice.gd` 那两个写死颜色除外）。
5. 实验室静态部分只在主题切换时重画，**不要**在 `_process` 里每帧 `queue_redraw()`。
6. 所有注释用中文。
7. `-s` 跑的测试脚本里拿不到自动加载单例，用 `root.get_node("Pal")`。
8. 测试不能读写玩家真实存档和设置。用 `-s` 跑的测试已经自动关掉存档，别绕过它。
9. 截图用 `bash tools/run_test.sh tests/xxx.gd`，会放到屏幕外运行，不抢鼠标和焦点。
