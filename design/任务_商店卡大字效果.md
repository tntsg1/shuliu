## 1. 目标（一句话）

商店（采购终端）的商品卡上，不再印整段简介。改成**一行大字写最关键的效果**，玩家扫一眼就知道这张卡管什么。整段简介移到**鼠标悬停卡片时弹出的说明框**里。

例子（只是示意，实际写法见第 4 节）：

| 物品 | 现在卡上的简介（保留，挪去悬停） | 新的大字 |
|---|---|---|
| 超导弯转磁铁 | 束流丢失概率降低 5 个百分点。 | 丢失率 −5% |
| 高流强注入器 | 基础科研价值 ×1.5，束流丢失概率 +5 个百分点。 | 价值 ×1.5 · 丢失 +5% |
| 高效束流引出器 | 主动引出时最终科研价值 +20%。 | 引出价值 +20% |
| 束流收集靶 | 束流丢失时返还 $（能级 × 2）。 | 丢失返 $能级×2 |

## 3. 卡面的新布局（`shop.gd` 的 `_card()`）

卡片尺寸不变：`const CARD := Vector2(272, 448)`。

从上到下：
1. **种类条 + 稀有度**（顶部 30px 彩条）：不变。
2. **图标**：不变。
3. **名称**（y≈204）：不变，保留“名字太长就缩字号”的逻辑。
4. **大字效果**（新）：放在名称下方，y 从 ≈250 开始。
   - 字体用 `Pal.bold`，字号 **26**。宽度放不下时逐级缩小到最小 18，和名称的缩字号写法一样（`while nfs > 18 and Ink.size(...).x > cr.size.x - 32: nfs -= 1`）。
   - 如果缩到 18 还放不下，允许换成两行：用 `Ink.para(self, Pal.bold, pos, text, width, 22, 2, col)`，最多 2 行。
   - 颜色用正文色 `Pal.c("text")`。正面效果的数字可以用 `Pal.c("green")`，负面效果（代价）的数字用 `Pal.c("red")`。**做不到逐段上色就整行用正文色，别硬做。**
   - 大字下方画一条淡分隔线：`draw_line(..., Color(el, 0.3), 1.0)`。
5. **原来的 `desc` 段落**：从卡面**删掉**（第 427 行那句 `Ink.para(... d.desc ...)`）。
6. **物品故事 `lore`**（蓝色手写体，靠底部）：保留，位置不变。
7. **价签、半价章、“点击购买 / 经费不够”、已购入印章**：全部不变。

## 4. `big` 字段怎么写（数据规则）

- **只从 `desc` 里提炼，不能编新效果**，数字必须和 `desc` 完全一致。
- 不超过 **12 个汉字宽**（数字和符号按半个字算）。
- 格式统一：
  - 用“丢失率 / 成功率 / 同步率 / 价值 / 引出价值 / 能级 / 经费 $”这些短词。
  - 百分点写成 `±N%`，倍数写 `×N`，钱写 `$N`。
  - 两个效果用 ` · ` 隔开，有代价的放后面。
  - 条件写在前面并加冒号，例如“能级≥10：丢失 −8%”。
- 实在提炼不了的（规则型效果，例如“每次实验首次失谐转化为保持稳定”），就写成一句短口号，例如“首次失谐不算数”。
- **用户的规矩：用户定稿的文案（`desc`、`lore`、`name`）一个字都不能改。** `big` 是新增的，写完后要单独列一张表交给用户审（见第 7 节）。

## 5. 商品卡的悬停说明框（新）

现在只有**下方物品栏里已有的物品**有悬停说明框（`_tip()`）。商品卡上没有。

要求：
- 鼠标停在商品卡上约 **0.35 秒**后，在卡片旁边弹出说明框。内容：名称、种类·稀有度、**完整 `desc`**、`lore`。这个框**不显示**“按住鼠标卖出 / +$卖价”那一行（商品还没买，不能卖）。
- 位置：卡片右边放得下就放右边，否则放左边。框不能超出商店面板 `pr_cache`。
- 键盘操作时（`kb == true`，`area == "shop"`，`sel` 选中的卡）也要显示。
- 动画沿用 `_tip()` 的横向展开写法（`tip_v` + `Ink.ease_out_back`）。可以抽一个公共函数，给 `_tip()` 加一个参数 `selling: bool` 控制底部那一行；也可以另写 `_card_tip()`。**两种都行，选改动小的。**
- 卡片翻面动画进行中（`absf(flips[i]) < 0.9`）和已购入的卡**不弹**。

## 6. 代码规矩（必须遵守，项目里踩过坑）

1. **画字一律用 `Ink.text / Ink.para / Ink.size / Ink.para_size`**（`scripts/util/ink.gd`，有缓存）。不要用 `draw_string`、`get_string_size`，它们每帧新建文字很慢。
2. **不要用 `draw_circle`、带抗锯齿的 `draw_polyline`、`draw_rect(..., false)` 描边。** 要画圆用 `Ink.disc`，画框用 `Ink.frame`，画折线用 `Ink.pl`。
3. 画风是**哑光平涂、黑白加主题色，不发光**。不加光晕、不加渐变、不加边框装饰。
4. 颜色都从 `Pal.c("名字")` 取，暗色模式会自动换色。不要写死颜色（纸张底色 `Pal.c("paper")` 等）。
5. 所有回复和注释用中文。
6. `-s` 方式跑的测试脚本里拿不到自动加载单例（`Pal`、`Sfx`），要用 `root.get_node("Pal")`。
7. **测试不能读写玩家真实存档和设置**。用 `-s` 跑的测试已经自动关掉存档，别绕过它。
8. 测试截图不能抢鼠标、不能抢窗口焦点：截图用 `bash tools/run_test.sh tests/xxx.gd`（会自动放到屏幕外运行）。
